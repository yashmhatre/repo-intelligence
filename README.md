# Repo Intelligence

Token-efficient codebase intelligence for Git issues, PRs, and Databricks projects.

## Goal

Reduce LLM token usage by converting a repository into a graph and vector knowledge layer.

## Planned Features

- Parse Python, SQL, and Databricks notebooks
- Build dependency graphs in Neo4j
- Index functions with embeddings
- Map Issues → Commits → Files → Functions
- Generate impact analysis and implementation plans
